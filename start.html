01 / DOWNLOAD

インストール前の確認

QUARTERのWindows版はコード署名のない配布形式です。Windowsが発行元を確認できないため、警告が表示されることがあります。PCの保護設定によっては起動できません。

QUARTER for Windows

配布の準備中です。

無料でダウンロード ↓最新情報をXで見る ↗

このページのダウンロードボタンだけをご利用ください。ボタンの横にバージョンとSHA-256を表示します。ハッシュ値は破損確認用で、発行元の証明ではありません。

02 / INSTALL

表示された画面に合わせて進めます。

警告の種類によって、できることが異なります。

「WindowsによってPCが保護されました」

Microsoft Defender SmartScreenの警告です。公式配布元から入手したQUARTERで、発行元が未確認であることを理解して実行する場合は、次の順に進めます。

  1. 画面の「詳細情報」を選びます。
  2. ダウンロードしたQUARTERのファイル名を確認します。未署名版では発行元は不明と表示されます。
  3. 「実行」が表示されていれば選び、インストーラーの案内に従います。

Windowsのバージョンや組織の設定によって、文言や選択肢は異なります。「実行」がない場合は、下の項目をご確認ください。

「管理者として実行」は必要？

必要ありません。ダウンロードしたファイルを通常どおりダブルクリックしてください。インストール方法の選択で最初から選ばれている「現在のユーザーのみ」のまま進めると、管理者権限なしでインストールできます。

「Smart App Control がブロックしました」／ 実行できない

Smart App Controlにはアプリごとの許可設定がありません。その場合、このPCではQUARTERをご利用いただけません。保護機能を無効にしないでください。

会社や学校のPCでは管理者の方針が優先されます。許可が必要な場合は管理者へ確認してください。

Microsoftの説明を確認する ↗

ウイルス・脅威として検出された

実行を中止してください。除外設定や保護の無効化は行わず、ファイル名・バージョン・検出名をサポートへお知らせください。APIキーや会話履歴は送らないでください。

レッスンが始まらなくなった

Googleがモデルを更新・終了すると、QUARTERはあなたのAPIキーで使える新しいモデルへ自動で切り替えます。

それでも始まらない場合は、設定の「接続テストを実行」でどこが失敗しているかを確認してください。「Geminiのモデル」の「モデルを指定する」から、Googleの公式ドキュメントにあるモデル名を直接入力することもできます。

新しいバージョンに更新したい

新しいバージョンが出ると、QUARTER 1.0.1以降は設定の「このアプリについて」でお知らせします。「ダウンロードページを開く」を押すとこのページが開きます。

QUARTERは自動更新しません。レッスンを終了してQUARTERを閉じ、保存先のノートをバックアップしてから、このページで案内する新しいインストーラーを実行してください。

ユーザーデータを削除する必要はありません。インストール先と学習データは別々に保存されます。

03 / SPEAK

準備ができたら、話してみましょう。

  1. Gemini APIキーを登録

    初回セットアップからGoogle AI Studioの取得手順を確認できます。Geminiの利用料はGoogleの料金・利用枠に従い、あなたのGoogleアカウントに直接発生します。

  2. マイクを許可して、レベルを設定

    3分のスキルチェックで話しやすいレベルを確認できます。音が出ない場合はPCの入出力設定も確認してください。

  3. レッスンを開始し、終了後に保存

    声で会話し、終了して保存すると学習ノートが残ります。ノートはNotesからいつでも読み返せます。
